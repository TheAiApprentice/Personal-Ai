# Foundry VTT Export

## Instructions

**Creator control.** Use the creator's approved scope. Ask before introducing a gameplay mechanic or mandatory story structure; an unattended run must omit unapproved additions. Adventure clocks, countdowns, forced deadlines, timed escalation and substitute pressure tracks are excluded from this build. Never add them during generation, audit or repair, or penalize exploration/rest with a timer. Estimated session length, historical dates and ordinary rules durations are not adventure timers.

Export an installable Foundry core-13 module folder using the current shared map geometry. Scenes include a gridless background, walls and explicit doors. NPCs, locations and player-safe handouts become private-by-default journals. Numerical creatures become actors only through the selected system adapter. The included importer requires a GM click, creates new flagged documents, skips previously imported records, and never overwrites existing world content. Record exact target versions and separate schema/JavaScript tests from an actual Foundry import. Until the creator performs that import, the compatibility verification remains pending. No fake manifest URL or completed runtime proof is invented.

## Host contract

This built-in stage is executed by the application, not by a model pretending to have performed it. See skill.json and output.schema.json. Retain actual evidence; creator decisions are never fabricated.
