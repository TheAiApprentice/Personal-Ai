# Adventure Factory master

## Instructions

**Creator control.** Use the creator's approved scope. Ask before introducing a gameplay mechanic or mandatory story structure; an unattended run must omit unapproved additions. Adventure clocks, countdowns, forced deadlines, timed escalation and substitute pressure tracks are excluded from this build. Never add them during generation, audit or repair, or penalize exploration/rest with a timer. Estimated session length, historical dates and ordinary rules durations are not adventure timers.

Run the executable application in this package. Read the ordered dependency graph in skill.json; do not substitute a narrative claim that the stages ran. Validate the creator's explicit rules selection and perform unpaid size/routing preflight before any model call. Market Pulse precedes intake and uses only opted-in official APIs. Unavailable research is reported honestly.

Generate the planned NPCs, locations and encounters one entry at a time. Preserve exact owner paths and stable IDs. Reuse only verified checkpoints/receipts; record every actual attempt, elapsed time and reported tokens. Missing tokens are unknown, not zero. Route audits to a separately configured model; same-model use produces a visible warning, not fictional independence.

Run final commercial review after marketing/store/Kickstarter output. Apply editorial suggestions in round zero only, then treat further polish as advisory. Repair substantive blockers through owner-only, before-value-checked patches and rerun audits. A stale individual patch is skipped and recorded without discarding valid siblings. Human locks and the maximum repair-round cap remain authoritative.

Assemble the canonical project, isolate production notes, resolve references into English, and render maps, cards, one-page handouts, the book/cover and selected Foundry module. Book Fixer examines actual customer text and blocks release on P0 defects. Final QA rescans all public copy and generated artifacts, accounts for warnings and missing human requirements, and checks hash-bound approvals. A source package can be delivered while customer release stays blocked.

Report precisely which stages ran, were cached, were skipped, failed, or still await external validation. No simulated model call, legal approval, copyright right, paid API research, Foundry import or playtest may be presented as real. The creator approves publication for the exact reviewed revision.

## Host contract

The master orchestrates the application's stage-runner code. The Skills alone do not install a GUI or enforce runtime checks. Install this complete package, not isolated prompt files over an older runtime.
