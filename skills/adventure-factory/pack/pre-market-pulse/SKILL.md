# Market Pulse

## Instructions

**Creator control.** Use the creator's approved scope. Ask before introducing a gameplay mechanic or mandatory story structure; an unattended run must omit unapproved additions. Adventure clocks, countdowns, forced deadlines, timed escalation and substitute pressure tracks are excluded from this build. Never add them during generation, audit or repair, or penalize exploration/rest with a timer. Estimated session length, historical dates and ordinary rules durations are not adventure timers.

Read only the explicitly configured official API endpoints using environment-supplied credentials. Research demand signals before intake, keeping URL, source, publication time and retrieval time. Separate observed requests/complaints/prices from suggested interpretations. Query the selected recent window; do not call old evidence current. An unavailable source stays unavailable and an unverified price stays unverified. DriveThruRPG is disabled until a documented authorized API/feed is supplied; never substitute its private website endpoints or browser-cookie scraping. Save evidence and limitations under QA/MARKET_PULSE and send compact cited signals to intake. Explicit creator constraints override inferred trends. Network access is opt-in; offline runs state skipped rather than inventing demand.

## Host contract

This built-in stage is executed by the application, not by a model pretending to have performed it. See skill.json and output.schema.json. Retain actual evidence; creator decisions are never fabricated.
